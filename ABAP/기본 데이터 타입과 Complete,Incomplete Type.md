# 기본 데이터 타입과 Complete, Incomplete Type

## 데이터 타입이란?

데이터 타입은 저장할 데이터의 종류와 표현 방식 등을 결정하는 기준이다.

ABAP은 문자, 숫자, 날짜, 시간, 바이트 데이터 등을 다루기 위한 기본 타입을 제공한다.

## Complete Type이란?

타입 자체에 필요한 기술적 속성이 모두 정의되어 있어, 길이나 소수 자릿수 등을 추가로 지정하지 않고 사용할 수 있는 타입

| 타입 | 의미 |
|---|---|
| i | 4바이트 정수 |
| int8 | 8바이트 정수 |
| f | 이진 부동소수점 수 |
| decfloat16 | 유효숫자 16자리의 십진 부동소수점 수 |
| decfloat34 | 유효숫자 34자리의 십진 부동소수점 수 |
| d | 날짜, YYYYMMDD 형식 |
| t | 시간, HHMMSS 형식 |
| string | 가변 길이 문자열 |
| xstring | 가변 길이 바이트 문자열 |

DATA lv_count TYPE i.
DATA lv_text  TYPE string.

string은 실제 문자열의 길이가 변하지만, 타입을 정의할 때 추가로 지정해야 할 속성이 없으므로 Complete Type

## Incomplete Type이란?

타입 이름만으로는 길이 등의 기술적 속성이 모두 정해지지 않고, 추가 속성을 지정하여 구체화하는 타입

| 타입 | 의미 | 구체화할 속성 |
|---|---|---|
| c | 고정 길이 문자 필드 | 문자 길이 |
| n | 숫자 문자로 구성되는 고정 길이 필드 | 문자 길이 |
| x | 고정 길이 바이트 필드 | 바이트 길이 |
| p | 팩 십진수 | 바이트 길이와 소수 자릿수 |

DATA lv_code   TYPE c LENGTH 10.
DATA lv_amount TYPE p LENGTH 8 DECIMALS 2.

- lv_code: 문자 10자리
- lv_amount: 저장 공간 8바이트, 소수 자릿수 2자리
- n은 숫자를 문자 형태로 다루는 타입이며, 정수 타입과 구분한다.

단, DATA 선언에서는 길이 등을 생략하면 기본값이 적용되는 경우가 있다. Incomplete Type이라고 생략 시 반드시 문법 오류가 발생하는 것은 아님
