
# Classic ABAP,ABAP Objects,Modern ABAP의 흐름

ABAP은 시대에 따라 절차 중심에서 객체지향으로 확장되었으며, 현대적인 문법과 모델 중심의 개발 방식으로 발전해 왔다.
엄밀한 버전 구분보다는 각 시기에 사용된 개발 방식의 변화로 이해할 수 있다.

## Classic ABAP

- 처리 순서와 절차를 중심으로 프로그램 구성
- 전통적인 리포트와 SAP GUI 화면 프로그램 개발에 활용
- 서브루틴과 함수 모듈 등으로 기능을 분리하고 호출
- 데이터 조회 -> 가공 -> 출력과 같은 처리 흐름 중심

  
  서브루틴(Subroutine) :
  - 주로 같은 프로그램 안에서 처리 로직을 분리할 때 사용하는 방식
  - FORM ... ENDFORM으로 정의하고 PERFORM으로 호출
  
  함수 모듈( Function Module ) :
  - 여러 프로그램에서 공통으로 호출할 수 있도록 만드는 별도의 개발 객체
  - 함수 그룹( Function Group ) 안에서 관리하며 CALL FUNCTION으로 호출
  - 입력값, 출력값, 예외 등을 정의하여 기능 제공

## ABAP Objects

- ABAP에 객체지향 기능을 추가한 확장
- 클래스와 객체를 중심으로 관련 데이터와 기능을 묶어서 관리
- 속성과 메서드를 이용하여 역할별로 프로그램 구성
- 상속뿐 아니라 다른 객체의 메서드를 호출하는 방식으로도 기능 재사용

## Modern ABAP과 현대적인 개발 방식

- 인라인 선언과 표현식 등 현대적인 문법 활용
- 객체지향 구조와 함께 사용하여 코드를 간결하게 작성
- CDS, RAP을 활용하는 개발에서는 업무 객체와 모델을 중심으로 구성

## 요약

- Classic ABAP : 처리 절차 중심
- ABAP Objects : 클래스와 객체 중심
- 현대적인 ABAP 개발 : 새로운 문법과 CDS·RAP 기반의 모델 중심 개발로 확장

이전 방식이 완전히 사라진 것은 아니며, 기존 프로그램에서는 전통적인 코드와 새로운 문법이 함께 사용될 수 있다.
