# Client와 회사코드, 관리회계영역의 역할과 관계

## Client란?

Client는 SAP 시스템 안에서 업무 데이터와 사용자 정보 등을 논리적으로 구분하는 단위
하나의 Client 안에 여러 회사코드와 조직 구성 가능. 기업집단 전체를 하나의 Client로 표현하기도 하나, Client 자체가 반드시 기업집단을 의미 X

그렇다면 하나의 큰 그룹사의 경우에는 하나의 Client로 구성하는가? 무조건 그렇다고 볼 수는 없다.

크게 두 가지로 경우를 나눠서 생각하면
1. 회사별로 독립적인 업무 환경이 필요한 경우
    - 같은 계열사라고 하더라도 업무 데이터와 Client별 설정을 독립적으로 관리할 필요가 있다면 Client 분리를 검토한다.
      반대로, 공통의 기준을 가지고 운영한다면 같은 Client에서 회사코드로 분류하는 것을 고려한다.
2. 테스트나 교육용 환경을 구분하는 경우
    - 실제 업무 데이터에 영향을 주지 않고 연습하도록 별도의 Client를 구성하기도 한다. 다만 개발, 테스트, 운영은 별도 SAP 시스템으로 나누기도 하여 모두 Client만으로 구분하는 것은 아니다.


## 회사코드란?

회사코드( Company Code )는 독립적인 회계 장부와 재무제표를 작성할 수 있는 외부회계의 최소 조직 단위
FI에서 거래를 기록할 때 어느 회사코드의 거래인지를 구분함

* 회사코드별로 자산, 부채, 수익, 비용 등을 기록
* 회사코드별로 재무상태표와 손익계산서를 작성 가능
* ex) 한국 법인과 미국 법인을 각각 별도의 회사코드로 관리 가능

반드시 법인과 회사코드가 1:1로 대응되는 것은 아님. 왜?
예를 들어 한국 법인의 일본 지점에서 현지 회계·세무 요건 등에 따라 독립적인 장부 관리가 필요하다면, 별도 회사코드를 구성 가능
다만, 지점별 매출이나 비용을 비교하는 정도라면 굳이 회사코드를 분리할 필요 X

## 관리회계영역이란?

관리회계영역(Controlling Area)은 기업 내부의 비용과 수익을 관리·분석하기 위한 조직 단위

CO에서 비용이 어디에서 발생했는지, 어느 부서나 제품에 귀속되는지 등을 관리하는 기준이 됨

 * 하나의 관리회계영역에 하나 또는 여러 회사코드를 배정 가능
 * 여러 회사코드를 하나의 관리회계영역에 배정하면 공통된 관리회계 기준으로 비용을 관리 가능
 * 여러 회사코드를 하나의 관리회계영역에 함께 배정하려면 공통 운영 계정과목표 등 일정한 조건을 충족해야 함

 일정한 조건 :
 1. 같은 Client에 속해야 함
 2. 운영 계정과목표가 같아야 함
 3. 회계연도와 기간 구분이 일치해야 함

## Client, 회사코드, 관리회계영역의 관계

```
ex)

  Client 100
    ├─ 회사코드 1000: A 법인
    ├─ 회사코드 2000: B 법인
    ├─ 회사코드 3000: C 법인
    ├─ 회사코드 4000: D 법인
    └─ 회사코드 5000: E 법인

  관리회계영역 배정
    회사코드 1000 ─┐
                  ├── 관리회계영역 A000
    회사코드 2000 ─┘
```

회사코드 1000과 2000을 하나의 관리회계영역에 배정

A 법인과 B 법인은 각각의 회사코드에서 회계장부와 재무제표를 작성
반면, 내부 비용 관리가 필요할 때는 두 회사코드를 같은 관리회계영역에 배정하여 공통된 기준으로 관리 가능

즉, 회사코드와 관리회계영역은 단순히 조직의 크고 작음을 구분하는 개념이 아닌, 외부회계와 내부 관리라는 서로 다른 목적을 가진 조직 단위

## 요약

- Client: SAP 시스템 안에서 업무 데이터를 논리적으로 구분하는 단위
- 회사코드: 독립적인 장부와 재무제표를 작성하는 외부회계 단위
- 관리회계영역: 비용과 수익을 관리·분석하는 내부 관리 단위
