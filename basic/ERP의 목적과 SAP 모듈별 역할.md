# ERP의 목적과 SAP 모듈별 역할

## ERP란?

ERP ( Enterprise resource planning ) -> 전사적 자원 관리
기업의 재무, 회계, 인사, 생산, 물류, 공급망, 조달 등의 핵심 경영 자원과 프로세스를 하나의 통합 시스템으로 관리하는 경영전략 및 소프트웨어 솔루션
- 정보기술 주도로 기업 업무 프로세스 재설계를 통해 기업 경쟁력을 확보
- 핵심적인 비즈니스 업무의 간편화 및 내부 연계성 증진
- 내외부 실시간 정보공유를 통해 의사결정 속도 향상 및 위험요소 제거

##  SAP Module

SAP 모듈 대표적으로 SD, MM, PP, HR, FI, CO 등의 모듈이 존재

- SD ( Sales & Distribution, 영업유통관리 ) : 사전영업활동, 판매주문처리, 출하관리, 대금청구 및 고객관리 등 지원
- MM ( Materials Management,  자재관리 ) : 자재소요량계획(MRP), 구매주문처리, 송장검증, 재고관리 등 지원
- PP ( Production Planning, 생산관리 ) : 생산계획 수립, 생산실적처리, 자재구성표(BOM) 및 공정(Routing)과 같은 생산기준정보 관리 지원
- HR ( Human Resources, 인적자원관리 ) : 조직관리, 종업원들에 대한 채용, 교육훈련, 인재개발, 성과평가와 같은 인사관리, 급여처리 및 후생복리와 같은 보상관리 등 지원
- FI ( Financial Accounting, 재무회계 ) : 총계정원장, 매입채무, 매출채권, 고정자산 관리 및 재무제표 생성 기능 등을 제공
- CO ( Controlling, 관리회계 ) : 간접비관리, 제조원가관리, 손익분석 등의 관리적인 의사결정을 위한 정보를 제공


## 모듈 간 연계

ERP의 중요한 특징은 각 업무를 개별적으로 관리하는 것에 더해 공통 데이터와 문서를 통해 서로 연결한다는 점

업무의 흐름 상 연계 예시
1. SD -> FI
   SD의 청구 단계에서 FI와 연계. 청구 문서 확정 시점에 매출 계정과 부가세 계정이 FI 전표에 반영.
   기업이 매출을 인식하는 시점.
2. MM → FI
   자재 입고나 공급업체 송장 처리 시 FI와 연계.
   재고자산의 증가와 공급업체에게 지급할 채무 등이 회계에 반영.
