# 플랜트,저장위치,구매조직,영업영역의 구분

## 플랜트란?

플랜트( Plant )는 생산, 조달, 재고관리 등의 물류 업무를 구분하는 조직 단위
생산 공장 뿐만 아니라 물류센터, 서비스 사업장 등으로 구성 가능

* 하나의 플랜트는 하나의 회사코드에 배정
* 회사코드 : 플랜트 = 1 : N
* 플랜트별로 자재의 조달, 생산, 재고 관련 정보를 관리 가능
ex) 같은 법인 내에서 생산 공장과 물류센터를 각각 별도의 플랜트로 구성 가능

## 저장위치란?

저장위치( Storage Location )는 플랜트 안에서 재고를 구분하여 관리하는 조직 단위
실제 창고를 기준으로 나눌 수도 있고, 관리 목적에 따라 논리적으로 구분도 가능

* 하나의 플랜트에 여러 저장위치 구성 가능
* 저장위치는 플랜트와 함께 식별
* 다른 플랜트에서 같은 저장위치 코드를 사용 가능

```
회사코드 1000: A 법인
├─ 플랜트 1100: 생산 공장
│  ├─ 저장위치 0001: 원자재 창고
│  └─ 저장위치 0002: 완제품 창고
└─ 플랜트 1200: 물류센터
   └─ 저장위치 0001: 상품 창고
```
플랜트 1100의 저장위치 0001과 플랜트 1200의 저장위치 0001은 서로 다른 저장위치

## 구매조직이란?

구매조직( Purchasing Organization )은 자재나 서비스의 구매를 담당하고, 공급업체와 구매 조건을 협의하는 조직 단위

* 가격 납품 조건 등 공급업체와의 구매 조건 관리
* 하나의 플랜트만 담당하거나 여러 플랜트의 구매를 함께 담당도 가능
* 조직 구성에 따라 여러 회사코드에 걸쳐 구매를 담당 가능
ex) 생산 공장과 물류센터가 각각 자재를 사용하더라도 구매는 하나의 중앙 구매조직에서 함께 담당 가능

즉, 플랜트는 물류 업무가 이루어지는 단위, 구매조직은 구매를 책임지는 단위

## 영업영역이란?

영업영역( Sales Area )은 판매 업무를 구분하는 세 가지 조직 요소의 조합

영업영역 = 영업조직 + 유통경로 + 제품군

* 영업조직( Sales Organization ) : 제품이나 서비스의 판매를 책임지는 조직
* 유통경로 ( Distribution Channel ) : 도매, 소매, 직접판매 등 고객에게 판매하는 경로
* 제품군( Division ) : 판매하는 제품이나 서비스를 구분하는 분류

ex)
  영업조직 : 국내 영업조직     영업조직 : 국내 영업조직
  유통경로 : 도매              유통경로 : 직접판매
  제품군 : 가전제품            제품군 : 식품
-> 같은 영업조직이라도 유통 경로나 제품군이 다르면 서로 다른 영업영역

## 조직 간 배정 관계

각 조직은 업무 목적에 따라 서로 연결되며, 단순한 하나의 상하 구조로만 구성되지는 않음

### 회사코드와 플랜트

* 하나의 회사코드에 여러 플랜트를 배정 가능
* 각 플랜트는 하나의 회사코드에 속함
* 회사코드 : 플랜트 = 1 : N

### 플랜트와 저장위치

* 하나의 플랜트에 여러 저장위치를 구성 가능
* 각 저장위치는 해당 플랜트에 속하며, 플랜트와 함께 식별
* 플랜트 : 저장위치 = 1 : N

### 구매조직과 플랜트

* 하나의 구매조직이 여러 플랜트의 구매를 담당 가능
* 하나의 플랜트에 여러 구매조직을 배정하는 것도 가능
* 구매조직 : 플랜트 = N : M

구매조직을 특정 회사코드에 배정하면 해당 회사코드의 플랜트들을 대상으로 구매를 담당
여러 회사코드에 걸쳐 구매를 담당하는 경우에는 구매조직을 특정 회사코드에 배정하지 않고, 담당할 플랜트들에 배정

### 회사코드와 영업조직

* 하나의 회사코드에 여러 영업조직을 배정 가능
* 각 영업조직은 하나의 회사코드에 속함
* 회사코드 : 영업조직 = 1 : N

### 영업조직·유통경로와 플랜트

* 영업조직과 유통경로의 조합에 납품을 담당할 플랜트를 배정
* 하나의 조합에 여러 플랜트를 배정 가능
* 하나의 플랜트도 여러 영업조직·유통경로 조합에 배정 가능

## 요약

* 플랜트: 생산·조달·재고관리 등 물류 업무를 구분하는 단위
* 저장위치: 플랜트 안에서 재고를 구분하는 단위
* 구매조직: 구매와 공급업체 협상을 책임지는 단위
* 영업영역: 영업조직·유통경로·제품군을 조합하여 판매 업무를 구분하는 단위
